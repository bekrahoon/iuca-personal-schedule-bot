# Личное расписание IUCA — Telegram-бот

Бот для тех, у кого пары собраны с разных курсов. Расписание своё, личное, и правится:

- **📸 по фото** — отправил скрин/фото расписания (можно с подписью «возьми только IT-224» или «это замена на среду») → бот показывает, что поменяется → «✅ Применить»;
- **💬 текстом** — «перенеси Machine Learning на четверг 14:45», «в пятницу пары нет»;
- **📚 из общего расписания IUCA** — ищешь предмет (`Testing`, `Machine`, фамилия препода), выбираешь секцию нужной группы, добавляешь все её пары разом;
- **✏️ вручную** — удалить пару 🗑 или добавить ➕ кнопками.

Плюс «Сегодня / Завтра / Неделя», напоминания за 5–30 минут до пары и `/export` в JSON.

## Запуск

1. Создай бота у [@BotFather](https://t.me/BotFather) → получи `BOT_TOKEN`.
2. Получи бесплатный ключ Gemini в [Google AI Studio](https://aistudio.google.com/apikey) → `GEMINI_API_KEY` (нужен только для фото/текстовых команд; без него работают поиск по IUCA и ручное редактирование).
3. Узнай свой Telegram ID у [@userinfobot](https://t.me/userinfobot) → `OWNER_ID` (чтобы бот отвечал только тебе).
4. ```bash
   pip install -r requirements.txt
   cp .env.example .env   # и заполни значения
   python bot.py
   ```

## Файлы

| Файл | Что внутри |
|---|---|
| `bot.py` | хендлеры, меню, напоминания |
| `ai_editor.py` | разбор фото/команд через Gemini (JSON по схеме) |
| `storage.py` | хранение: `data/<telegram_id>.json` |
| `iuca_schedule.json` | общее расписание IUCA (из tgbotiuca), для поиска предметов |

Когда в универе обновят расписание — просто замени `iuca_schedule.json` (формат тот же, что в tgbotiuca). Твоё личное расписание при этом не пострадает.

## Деплой

Подойдёт любой сервер/VPS или тот же Azure App Service, что в исходном репо: команда запуска `python bot.py`, переменные окружения — как в `.env.example`. Папка `data/` должна сохраняться между перезапусками (или задай `DATA_DIR` на постоянный диск).
